# ML Mnist 詳細設計書

## 機能概要
手書き数字画像（MNIST）を入力として、
対応する数字（0〜9）を分類する画像認識モデル。

## 入力データ仕様
- データセット：MNIST
- 画像サイズ：28×28ピクセル
- チャネル数：1（グレースケール）
- 前処理：
  - 0〜255 → 0〜1 に正規化
  - ラベルはワンホットエンコーディング

## モデル構造
本システムでは、画像の特徴抽出に優れたCNN（畳み込みニューラルネットワーク）を採用
| 層（レイヤー） | 設定値・パラメータ | 役割・設計意図 |
| --- | --- | --- |
| Conv2D(入力：28×28×1) | 32 filters, (3,3), ReLU| 画像の局所的な特徴（線や角）を抽出 |
| MaxPooling2D | (2,2) | 重要な特徴を維持したまま解像度を圧縮 |
| Conv2D | 64 filters, (3,3), ReLU | より複雑な模様や形状を抽出 |
| MaxPooling2D | (2,2) | さらなる情報の圧縮と計算コストの削減 |
| Flatten | - | 抽出した2次元の特徴を1次元配列に変換 |
| Dropout | rate=0.5 | 過学習の抑制（汎用性の向上） |
| Dense | 64 units, ReLU | 抽出された特徴に基づいた分類計算 |
| Dense(出力)(多クラス分類) | 10 units, Softmax | 0〜9の各数値である確率を出力 |

## 学習プロトコル
精度の高いモデルを効率的に生成するための設定。
- 最適化アルゴリズム: Adam（学習率を自動調整し、収束を早めるため）
- 損失関数: categorical_crossentropy（多クラス分類に最適）
- 学習停止制御 (EarlyStopping):
    - 検証用データの損失（val_loss）を監視。
    - 3エポック連続で改善が見られない場合に学習を打ち切り、過学習を防止。
    - 最高の精度を記録した重みを自動的に復元する設計。
- 学習データの10%を検証用データとして使用（validation_split=0.1）。
